# 💸 Expense Tracker

A clean, multi-page **personal expense & income tracker** built with vanilla JavaScript — track where your money goes, all stored privately in your own browser.

## ✨ Features

- 📊 **Dashboard** — at-a-glance balance, income & expense summary
- 💰 **Income tracking** — log income entries
- 🧾 **Expense tracking** — categorize and record expenses
- 📋 **Records** — browse full transaction history
- 👤 **Profile** — personal account page
- 🔐 **Auth pages** — login & signup flows
- 💾 **Private storage** — everything stays in your browser via `localStorage`

## 🛠️ Tech Stack

| Layer      | Technology                    |
| ---------- | ----------------------------- |
| Frontend   | HTML, CSS, Vanilla JavaScript |
| Storage    | localStorage (browser)        |
| Build step | None ✅                       |

## 🚀 Getting Started

No installation needed:

```bash
git clone https://github.com/deva2006-raut/client-.git
cd client-
```

Then open **`index.html`** in your browser — or serve it locally:

```bash
npx serve .
# or
python -m http.server 8080
```

## 📁 Pages

```
├── index.html      # Dashboard
├── login.html      # Login
├── signup.html     # Sign up
├── income.html     # Add income
├── expense.html    # Add expense
├── records.html    # Transaction history
└── profile.html    # User profile
```

> ⚠️ Data is stored in your browser's `localStorage` — clearing browser data will reset your records.
